# 永夜抄 3.3.1：录像保存、暂停暗化与 OGG 音乐

结果界面的录像行号为 0–14，文件和外部保存接口为 1–15。`GameApplication::ResultIo` 现在在读取和保存时一致地转换行号，修复第一行没有文件、其余行错位，以及占用槽位未正确提示覆盖的问题。实际结算界面已验证第一、十五槽位，覆盖确认、退出重启和录像播放。

`GameplayScene::load` 重置菜单后，应用启用平台已实现的截图功能。暂停与续关使用原版 `capture.anm` 的背景动画；恢复时照常消退，不使用网页 CSS 遮罩。截图的亮度检查与原版菜单控制、动画状态对照均通过。

21 首 BGM 从原版 PCM 转为 Ogg Vorbis，44,100 Hz、双声道，编码压缩参数 0.4。OGG 是有损格式；保留每曲的采样帧数、循环起点和终点，不宣称 PCM 无损相同。正式 C++ 音频使用 stb_vorbis / miniaudio 文件解码，通过 SDL3 输出，已禁用 FLAC 解码。音乐总计 67,203,168 字节（约 67.2 MB），含游戏主体的资源包共 126,734,173 字节。

旧版首次更新只下载 OGG 音乐，复用现有 DATA，保留浏览器存档与录像。取消更新不会启动不兼容的旧 FLAC 资源；更新完成后可离线游玩。正式发布目录不包含 FLAC 音乐。开发目录里的旧发布备份供回退使用。

验证记录在发布目录 `validation`：

- `replay-pause.json`、`replay-pause-slot15.json`：实际界面录制、保存、占用确认、重启、播放，暂停亮度与恢复。
- `ogg-decoder.json`：Wasm 中用正式 Vorbis/miniaudio 解码全部曲目，核对全长及循环边界采样。
- `ogg-update.json`：移动视口启动器升级、DATA 复用、录像持久化、离线音乐播放。
- `smoke.json`：正式 C++/SDL3 游戏、音频输出与浏览器保存。
- `replay-character0-final.json`：100,153 帧路线，3,339 个抽样状态与已验证基准一致。
- `repair-regression.log`：5 项 C++ 测试，包括原版菜单/录像导出对照、12 角色录制回放和应用/结果场景。

浏览器自动化在桌面运行；不代表已在实体手机上完成帧率测试。
